## 레이아웃

- 최대 컨테이너: 1280px
- 섹션 상하 패딩: 96px (데스크탑), 60px (모바일)
- 컨테이너 좌우 패딩: 24px
- 카드 간격: 20px
- 모서리 반경: 8px (카드), 4px (버튼), 50px (필)

## 화면별 레이아웃

### 홈페이지 (allbirds 참고)
1. 히어로: 풀스크린 이미지 + 텍스트 오버레이 + CTA
2. 베스트셀러: 4열 상품 그리드
3. 기능 소개: 3열 아이콘 섹션
4. 신제품: 2-3열 대형 카드
5. 소재/기술 이야기: 좌우 분할 레이아웃
6. 고객 리뷰: 슬라이더
7. 뉴스레터 구독

### 상품 목록
- 상단: 카테고리 탭 + 필터
- 좌: 필터 패널 (데스크탑) / 상단 필터 (모바일)
- 우: 3-4열 상품 그리드

### 상품 상세
- 좌: 이미지 갤러리 (메인 + 썸네일)
- 우: 상품명, 가격, 색상선택, 사이즈선택, 담기버튼
- 하단: 탭 (설명/기능/배송/리뷰)

> (번호 09는 `04_운영/09_SecurityGuide.md`가 이미 쓰고 있어 11번으로 정함.)

> 키 이름 등록 대장은 `factory\KEYS.md`.

## 한눈에 보는 구성

| 영역 | 쓰는 서비스 | 비고 |
|---|---|---|
| 프론트엔드 | React 18 + Vite 6, React Router 6, CSS Modules | `package.json` |
| 관리자 통계 그래프 | Recharts | `package.json` |
| 데이터베이스 | **Firebase Firestore** | `src/firebase.js`, 상품 조회 `src/services/productService.js`. 규칙 사본: `firestore_rules.txt` |
| 로그인 | **Firebase Authentication** (이메일 + Google 로그인) | `src/pages/LoginPage.jsx` |
| 파일 저장 | **Firebase Storage** | `src/firebase.js`에서 연결. 규칙 사본: `storage_rules.txt` |
| 사이트 배포 | **Vercel** (GitHub 연결 자동 배포, 도메인은 후이즈 보유) | `vercel.json`(모든 주소를 첫 페이지로 연결), `docs/03_시스템/07_DeploymentGuide.md` |
| 결제 | 토스페이먼츠 v2 (추후 연동) | `CLAUDE.md`. 결제 화면 `CheckoutPage.jsx`에 카카오페이·네이버페이·토스페이 선택지가 있으나 실제 연동은 확인 필요 |
| 사용자 분석 | Firebase Analytics 추정 | `VITE_FIREBASE_MEASUREMENT_ID` 키가 있음 — 코드 사용 여부 확인 필요 |
| 자동 검사 | Husky(커밋 전 자동 실행), 테스트는 아직 없음 | `package.json` |
| 소스 코드 저장소 | **GitHub** (`pigletmin19-rgb/bareunbal`) | `git remote -v`로 확인. 배포 가이드에 적힌 저장소 이름(`shoes-homepage`)과 다름 — 확인 필요 |

## 커밋 전 비밀값 유출 자동검사 (2026-09-24 신설)

`scripts/check-staged-secrets.js` — `git commit` 직전에 자동 실행되어, 스테이징된 파일에 비밀값으로
보이는 패턴(GitHub/Google/Anthropic/OpenAI/AWS/Slack 키 형식, 개인키 블록, `VITE_*_SECRET/TOKEN/
PASSWORD/API_KEY=` 이름 패턴)이 있으면 커밋 자체를 막는다. 배포 시점 검사(`launch_gate_check.js`)
보다 훨씬 이른 시점에 막아서 비밀값이 git 역사에 아예 안 남게 하는 게 목적
(관리자 대시보드 비밀값 공개 노출 사고, 2026-09-21 재발방지). 오탐이면 그 줄에
`// secretlint-ignore` 주석을 붙인다. 자세한 배경: `factory\완전자동화_체크리스트.md` G절.

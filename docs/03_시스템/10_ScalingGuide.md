---

## 현재 기술 구조

- 프론트엔드: React + Vite
- 인증/DB: Firebase
- 호스팅: Vercel
- 결제: 토스페이먼츠 (예정)

Firebase가 백엔드 역할을 대신하는 구조로, 소규모 쇼핑몰에 적합한 표준적인 방식.

---

## 현재 구조로 충분한 경우

- 월 주문 1,000건 이하
- 동시 접속자 수백 명 이하
- 단순한 상품/주문 관리

---

## 백엔드 서버 도입을 고려해야 하는 경우

- 월 주문 5,000건 이상
- 복잡한 할인/정산 로직 필요
- 재고 실시간 동기화 필요
- 외부 ERP/물류 시스템 연동 필요
- Firebase로 해결되지 않는 기능 필요

---

## 확장 방향

1. **단기**: 현재 구조 유지, Firebase 기능 추가
2. **중기**: 백엔드 서버(Node.js 등) 추가, Firebase와 병행
3. **장기**: 전용 서버 + DB로 전환, 외부 시스템 연동

## 서비스 목적

- 해결하는 문제: 척추 건강과 바른 자세를 위한 의료기반 기능성 신발의 부재
- 핵심 가치: 정형외과 기반 설계의 기능성 신발을 온라인으로 편리하게 구매

---

## 브랜드 컨셉

- 브랜드명: TERRA (임시)
- 슬로건: "당신의 발이 척추를 바꿉니다"
- 포지셔닝: 의료기반 기능성 슈즈 전문 브랜드
- 타겟: 척추/무릎/발 건강에 관심 있는 30~60대, 장시간 서서 일하는 직종

---

## 타겟 고객

- 1차: 척추 질환자, 발 건강 이상자 (30-60대)
- 2차: 건강한 자세를 원하는 직장인, 요양보호사, 의료종사자
- 3차: 성장기 자녀를 위한 부모 (키즈 라인)

---

## 기술 스택

- 프론트엔드: React 18 + Vite
- 스타일: CSS Modules
- 라우팅: React Router v6
- 상태관리: React Context API
- 호스팅: Vercel (Firebase 대신)
- 결제: 토스페이먼츠 v2 (추후 연동)
- 도메인: 후이즈(Whois) 보유 중
